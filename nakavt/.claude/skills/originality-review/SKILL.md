# Originality Review (Dept: Scouting & Identity — IP GATE)

## Checklist (reject on any IP failure)
- [ ] **IP** — name original (not a real player); team fictional (not a real
      franchise); no real logo; uniform is an original design, not a 1:1 real kit.
- [ ] **Balance** — stats traded off; nothing strictly dominant.
- [ ] **Readability** — distinct silhouette + colors; recognizable at HUD scale in 1s;
      not a near-duplicate of another character.
- [ ] **Schema** — fields match `src/config.js` CHARACTERS so it renders.
- [ ] **Coverage** — the roster spans varied archetypes; add one if a role is missing.

## Output
`APPROVE` or `CHANGES REQUESTED:` with a specific list. Never approve real-IP output.
