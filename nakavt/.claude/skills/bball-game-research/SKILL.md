# Basketball Game Research (Dept: Research & Innovation)

## Method
1. Study shot timing/feedback, rebound races, streak/"on fire" systems, camera juice,
   particle use, and readable mobile UI in arcade/mobile basketball games.
2. For each idea, write a one-pager: **what** it is, **why** it fits NAKAVT, **how** to
   build it in vanilla Canvas 2D WITHOUT changing knockout rules / movement / shot
   mechanic / AI / state machine, and a rough **effort** estimate.
3. Flag engine limits honestly: only propose PixiJS/Phaser/Rive after proving Canvas 2D
   can't do it, comparing options, and getting orchestrator + user approval.

## Output
A ranked, implementable shortlist for the orchestrator to approve.
